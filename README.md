# Mempertahankan Kedaulatan Bangsa Dulu dan Kini

Presentasi web untuk tugas Sejarah Kelas XII, sub-topik
**Perundingan RI dengan Pihak Asing tentang Kedaulatan Ekonomi** —
membandingkan perundingan RI–Belanda 1945–1949 dengan tantangan ketahanan
energi Indonesia akibat ketegangan di Selat Hormuz.

**▶ Buka presentasi:** https://bakpia25code.github.io/sejarah-kedaulatan-bangsa/
