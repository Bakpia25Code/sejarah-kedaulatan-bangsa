## Cara membuka

Klik dua kali `index.html` — akan terbuka di browser (Chrome / Safari / Edge).
Tekan **F** untuk layar penuh sebelum mulai presentasi.

## Tombol saat presentasi

| Tombol | Fungsi |
|---|---|
| `→` / `Spasi` / klik | Slide berikutnya |
| `←` | Slide sebelumnya |
| `Home` / `End` | Slide pertama / terakhir |
| `1`–`9` | Lompat ke slide tertentu |
| `O` | Ikhtisar semua slide (klik untuk lompat) |
| `N` | **Catatan penyaji** — poin bicara untuk tiap slide |
| `F` | Layar penuh |
| `?` | Bantuan |
| `Esc` | Tutup panel |

> Tip: buka catatan penyaji (`N`) saat latihan — di situ ada poin-poin yang bisa
> diucapkan untuk setiap slide.

## Catatan penting

- Seluruh media sudah **diunduh ke folder `assets/`**, jadi presentasi tetap berjalan
  penuh **tanpa koneksi internet**.
- Jangan memindahkan `index.html` keluar dari folder ini, karena file media dipanggil
  dari `assets/img/` dan `assets/video/`. Kalau mau memindahkan atau mengirim,
  **pindahkan atau zip seluruh folder**.
- Semua media berlisensi Domain Publik, CC0, CC BY, atau CC BY-SA dari Wikimedia Commons
  (Nationaal Archief/Anefo, Polygoon & Open Beelden, IPPHOS, NASA/MODIS, Library of Congress,
  Global Solar Atlas). Kredit lengkap ada di slide 25.
